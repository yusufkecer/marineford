## 0.1.0-dev

- `marineford init` — imza anahtar cifti, marineford.yaml, .gitignore girisi.
- `marineford abi` — ABI fingerprint'i yazdirir.
- `marineford build` — patch paketini derler, lint'ler, sikistirir, imzalar.
- `marineford publish` / `rollout` / `revoke` — statik hedefe yayin ve manifest.
- `marineford doctor` — yayina hazirlik kontrolu.
